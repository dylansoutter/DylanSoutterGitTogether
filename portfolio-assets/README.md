# GitTogether portfolio media

These images were captured from the local frontend on September 23, 2026. The UI currently says **ProjectHub**. The dashboard, project listings, project creation dialog, and profile are prototype views with sample data; they are not evidence of saved projects or a completed end-to-end integration.

- `login-preview.png` and `register-preview.png`: auth forms, which submit to backend endpoints when a configured backend and database are running.
- `dashboard-preview.png`, `projects-preview.png`, `create-project-preview.png`, and `profile-preview.png`: prototype screens with sample data.
- `ui-walkthrough.gif`: a 24-second sequence of those captured UI screens. This is a visual walkthrough, not a recording of successful registration, login, database project creation, or profile updates.

No `.env` file, database connection string, JWT, password, or real user account was included in these assets.
